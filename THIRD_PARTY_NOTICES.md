# Third-party notices

Nothing from a third party is copied into this repository yet. The runner has no dependencies.

The desktop app (see `packages/desktop`) is planned to be built on [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH), which is MIT licensed. When DSH code is added, its full MIT LICENSE text will be put in this file, together with its copyright line.

The runner can start the `dsh` command as a helper over ACP. That runs DSH as a separate program on your machine and does not include its code here.
